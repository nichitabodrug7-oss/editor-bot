# Редактор-помощник — полностью бесплатный деплой (Render + Gemini)

Ни один из сервисов ниже не требует карты и не тратит денег при
обычном использовании студентами.

## Шаг 1. Токен бота
1. В Telegram напиши **@BotFather**.
2. `/newbot` → придумай имя и username (заканчивается на `bot`,
   например `zhurfak_editor_bot`).
3. Сохрани токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxx`.

## Шаг 2. Бесплатный ключ Gemini
1. Зайди на **aistudio.google.com/apikey** (нужен обычный Google-аккаунт,
   карта не требуется).
2. "Create API key" → сохрани ключ.
3. Бесплатный лимит — щедрый для учебного проекта (пачки запросов
   в минуту), карту привязывать не просят.

## Шаг 3. Код на GitHub
1. Зарегистрируйся на github.com, если нет аккаунта.
2. "New repository" → назови, например, `editor-bot`.
3. "Add file → Upload files" → перетащи `bot.py`, `requirements.txt`,
   `Procfile` → "Commit changes".

## Шаг 4. Деплой на Render
1. Зайди на render.com, зарегистрируйся через GitHub — карта не
   нужна для бесплатного тарифа.
2. "New +" → "Web Service" → выбери репозиторий `editor-bot`.
3. Настройки:
   - Runtime: Python 3
   - Build command: `pip install -r requirements.txt`
   - Start command: `python bot.py`
   - Instance type: **Free**
4. Пока не жми Deploy — сначала добавь переменные окружения
   (раздел Environment):
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1
   - `GEMINI_API_KEY` — ключ из шага 2
   - `WEBHOOK_URL` — сюда пока впиши что угодно, поправим на
     следующем шаге
5. Нажми "Create Web Service". Render соберёт проект и даст тебе
   адрес вида `https://editor-bot-xxxx.onrender.com`.
6. Скопируй этот адрес, зайди в Environment ещё раз и обнови
   `WEBHOOK_URL` на него (без слэша в конце). Сохрани — Render сам
   перезапустит сервис с правильным адресом.
7. Проверь в Telegram: напиши боту `/start`.

## Про "засыпание"
Бесплатный тариф Render останавливает сервис, если 15 минут никто
не писал. Следующее сообщение "будит" его — обработка первого
сообщения после паузы может занять до минуты, это нормально и не
означает, что бот сломался. Для учебного проекта с редким
использованием это не критично.

## Если понадобится больше
- Если станет тесно по лимитам Gemini — можно завести второй
  бесплатный ключ или дождаться сброса лимита (посуточный/помесячный,
  смотри в консоли Google AI Studio).
- Если захочешь, чтобы бот не засыпал — на Render это уже платная
  опция ($7/мес за постоянно активный сервис), но для начала это
  не нужно.
